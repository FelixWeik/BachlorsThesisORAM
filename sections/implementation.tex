\chapter{Implementation}
\label{ch:Implementation}

\label{sec:ImplementationTarget}
This research aims to scale ORAMs arbitrarily, using \textit{3-Party DUORAM} as an example.
The already existing \textit{DUORAM} implementation by Vadapalli et al. \cite{vadapalli2023duoram}\footnote{The original implementation by Vadapalli et al. can be found at https://git-crysp.uwaterloo.ca/iang/prac.git} is optimized for 64-bit values.
Larger values are not supported yet.
After further expanding the theoretical foundations of the \textit{DUORAM} and explaining the existing code, this chapter highlights and discusses the most promising approaches.
