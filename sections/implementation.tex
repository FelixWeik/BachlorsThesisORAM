\chapter{Implementation}
\label{ch:Implementation}

\label{sec:ImplementationTarget}
This research aims to make ORAMs, using \textit{DUORAM} as an example, indipendent from their storage size.
The already existing implementation of the \textit{DUORAM} by Vadapalli et al. \cite{vadapalli2023duoram} is optimized for 64-bit values.
Larger values are not supported yet.
Multiple solutions exist to perform this task.
This chapter explains the existing code and highlights, and discusses the most promising solutions.
